# mopidy-jellyfin-docker
A basic docker setup for mopidy-jellyfin

## Instructions

```
git clone https://github.com/Vigrond/mopidy-jellyfin-docker.git
cd mopidy-jellyfin-docker

# edit mopidy.conf with your parameters
# edit requirements.txt with any other mopidy extensions you may need

docker compose up -d
```
